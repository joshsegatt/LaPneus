# L.A Pneus - Atelier Mobile Genève & Vaud

Site officiel et plateforme de réservation pour **L.A Pneus** — Service de montage de pneus et entretien freins à domicile ou sur lieu de travail en Suisse (Genève et Vaud).

- **Domaine officiel :** [https://lapneus.ch](https://lapneus.ch)
- **Email officiel :** `info.lapneus@gmail.com`
- **Dépannage d'urgence :** `078 605 43 01`

---

## 🛠️ Stack & Architecture
- **Frontend :** HTML5 sémantique, CSS3 (Design Tokens, Responsive Mobile-First), JavaScript Vanilla.
- **Performance & SEO :** Schema.org JSON-LD (AutoRepair, LocalBusiness, FAQPage), Sitemap XML, Robots.txt, balises géolocalisées Suisse (CH-GE / CH-VD).
- **Hébergement :** Prêt pour déploiement Vercel (`vercel.json`) et Netlify (`netlify.toml`).

# Lancer le serveur local de test
